## Descripción
Sistema orientado a objetos desarrollado en Python, sin base de datos, que implementa:
- Manejo avanzado de excepciones (try/except/else/finally).
- Excepciones personalizadas.
- Generación de logs (sistema_fj.log).
- Uso de librería `rich` para una interfaz de consola dinámica y profesional.
